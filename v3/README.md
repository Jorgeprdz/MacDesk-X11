# MacDesk V3 / S25 Neo

- Android / One UI remains intact.
- XFCE runs natively in Termux ARM64.
- Termux:X11 is the X server.
- XFWM compositing is disabled for the stable base.
- `macdesk-gpu` opts individual apps into Zink -> Vulkan -> Turnip -> Adreno.
- `macdesk-browser` prefers Zen Light and can bridge to the Debian compatibility box.
- `macdesk-files` prefers Nautilus from the compatibility box and falls back to native Thunar.
